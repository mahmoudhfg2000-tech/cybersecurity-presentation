          Vocabulary
          
Threat · Vulnerability · Risk

        

        

          

            

            The attacker
            
Threat

            
Something that can cause harm.

          

          

            

            The weakness
            
Vulnerability

            
A weakness that can be exploited.

          

          

            

            The consequence
            
Risk

            
The likelihood of harm and how big its impact is.

          Injection
          

            When input becomes code
          

          

            Prevention for SQL injection: parameterized queries. For XSS:
            output encoding.
          

        

        

          

            

              
            

            

              
            

          

          

            
            
            
          

          

          

        

      

    


    
    

      

        

          Access control
          

            Broken Access Control
          

          

            A student reaches data that isn't theirs. Hiding a button is not
            enough: the server must check permissions on every request.
